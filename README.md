# EFA Billing Service · 운영비용 정산

## 운영 주소

- 서비스: https://efa-billing-service.vercel.app
- GitHub: https://github.com/carlintz/efa-billing-service
- Vercel 관리: https://vercel.com/carlintzhs-1766s-projects/efa-billing-service

`main` 브랜치를 운영 브랜치로 연결했습니다. 코드 변경은 GitHub에서 관리하며 Vercel이 연결된 저장소에서 빌드합니다. Vercel 팀의 기본 접근 보호 설정을 유지합니다. 이 저장소는 소스 공개 승인을 받아 public으로 관리하며, 원본 CSV·생성 Excel·인증정보는 저장소에 포함하지 않습니다.

브라우저에서 CSV를 읽어 5개 시트의 Excel을 생성하는 독립 배포용 정산 도구입니다. CSV와 생성 파일을 서버에 저장하지 않습니다. 서버는 정적 화면과 서울외국환중개 환율 조회만 제공합니다.

## 실행

Node.js 22에서 `npm ci`, `npm run build`, `node serve.mjs`를 실행하고 `http://localhost:4173`을 엽니다. `npm test`로 집계·환율 검증·Excel 생성 검사를 실행합니다. CSV 통합 검사는 `EFA_BILLING_FIXTURE` 환경변수로 로컬 CSV 경로를 지정했을 때만 실행합니다. 원본 청구 파일은 저장소에 포함하지 않습니다.

## 사용

1. billing.exported.csv를 업로드합니다. 파일의 최신 날짜에서 정산 대상월을 제안하며 직접 변경할 수 있습니다.
2. 정산 기간과 전월 USD 월평균 매매기준율을 확인합니다. 자동 조회가 실패하면 표시된 서울외국환중개 링크에서 기준월 환율을 확인하고 직접 입력합니다. 예시 환율을 실제 환율로 사용하지 마세요.
3. 요약과 상세를 확인하고 정산 Excel을 다운로드합니다. 미수집 날짜가 있어도 수집된 데이터로 다운로드할 수 있으며 파일에 미수집 상태를 표시합니다.

## 확정 규칙

- 정산 기간은 전월 15일~당월 14일, 양 끝 날짜를 포함합니다.
- RAW는 선택한 대상월의 전월 1일~대상월 파일 최신일입니다. 정산 기간 밖인 당월 15일 이후 데이터도 RAW에 보존합니다.
- APN2는 서울, APE1은 홍콩, 그 외는 공통입니다. MZC Discount Program은 리전과 무관하게 공통에서 원래 금액을 차감합니다.
- 그룹별 상품코드 기간 합계 내림차순으로 정렬하고, 순합계 0인 상품코드는 표시하지 않습니다.
- 정산 기간 USD 전체 합계를 환산한 뒤 공급가액을 원 단위 반올림합니다. 확정 공급가액의 10%를 다시 원 단위 반올림한 뒤 더해 청구 총액을 구합니다. Decimal.js의 십진 연산과 ROUND_HALF_UP을 사용합니다.
- 일자별 원화 값은 반올림하지 않습니다. 그룹별 원화 반올림 값의 합계와 전체 USD를 한 번에 환산한 공급가액은 원 단위 차이가 날 수 있으며, 전체 환산 공급가액을 청구 기준으로 사용합니다.
- 데이터가 없는 날짜는 0원과 구분합니다. 데이터가 존재하는 날짜라고 해서 AWS 청구의 확정·수집 완료를 보장하지는 않습니다.
- 프로젝트·계정이 여러 개이면 업로드 범위 전체를 합산합니다.

## 환율과 데이터

출처는 http://www.smbs.biz/ExRate/MonAvgStdExRate.jsp 입니다. 원래 HTTP 페이지를 먼저 크롤링하고, HTTPS 및 동일 기관 smbs.co.kr을 보조 경로로 시도합니다. 페이지 하단의 월평균 매매기준율 표에서 요청한 월과 USD가 정확히 일치하는 행만 채택합니다. 그래프 값이나 일별 환율은 사용하지 않습니다. 과거 월이 기본 표에 없으면 원문 form에서 읽은 필드명과 선택값으로 조회합니다. 외부 페이지의 접근 제한이나 구조 변경 시 직접 입력으로 안내합니다. 개발환경의 도메인 차단으로 실제 원문에 대한 실시간 검증에는 제한이 있습니다. 환율 입력 방식과 적용월은 Excel에 표시합니다.

Excel은 새 통합문서에 기존 5개 시트와 표 배치를 재구성합니다. 기존 파일의 내부 이름·필터·시트 설정을 가져오지 않습니다. 사용자가 업로드한 실제 원본은 웹사이트 소스에 포함하지 않습니다.

## 독립 배포와 관리

별도 GitHub 저장소와 Vercel 새 프로젝트로 관리하는 구성입니다. DB가 필요하지 않아 Supabase는 사용하지 않습니다. 설치·배포 및 기존 서비스 분리 기준은 [DEPLOYMENT.md](DEPLOYMENT.md)를 참고하세요.

- 프런트엔드: 브라우저 전용 JavaScript
- 환율 API: Vercel Node.js Function (`api/rate.mjs`)
- 배포 출력: `.vercel/output`
- GitHub Actions: 테스트 및 빌드 검증
- 원화 우선 요약, USD 보조 표시, 리전 비중 소수점 1자리 반올림
